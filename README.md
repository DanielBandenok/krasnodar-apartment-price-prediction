# krasnodar-apartment-price-prediction



| Раздел | Вопрос | Ответ |
|---|---|---|
| 1. Бизнес-задача | Что улучшаем? | Повышаем точность оценки рыночной стоимости квартир на вторичном рынке Краснодара. Цель — рекомендовать продавцам устанавливать обоснованную цену, а покупателям — оценивать адекватность стоимости предложения. |
| 1. Бизнес-задача | Что сделают с прогнозом? | Пользователь вводит характеристики квартиры и получает рекомендованную цену в рублях и индикатор, является ли цена рыночной. Результат можно использовать при размещении объявления или принятии решения о покупке. |
| 2. ML-задача | Для чего и когда прогноз? | Прогноз стоимости выполняется при оценке квартиры перед покупкой или размещением объявления, на основании известных признаков объекта. |
| 2. ML-задача | Таргет: как посчитать из данных? | Цена квартиры в рублях, указанная в объявлении о продаже. Для каждого объекта используется цена на момент сбора данных. |
| 2. ML-задача | Тип задачи | Регрессия. |
| 3. Данные и признаки | Откуда данные, сколько их? | ~11 000 объявлений о продаже квартир на вторичном рынке Краснодара. Основной источник — парсинг объявлений ЦИАН, вспомогательный — парсинг объявлений Авито. |
| 3. Данные и признаки | Признаки на момент прогноза | Общая/жилая площадь, площадь кухни, количество комнат, этаж, этажность дома, район, год постройки, тип дома, высота потолков, тип санузла, тип отопления. |
| 4. Метрика и проверка | Метрика | MAE |
| 4. Метрика и проверка | Бейзлайн без ML | Предсказываем стоимость квартиры на основе медианной цены квадратного метра для квартир с похожими характеристиками, умноженной на площадь объекта. |
| 4. Метрика и проверка | Как делим данные? | Данные разделяются на обучающую (80%) и тестовую (20%) выборки. Для подбора гиперпараметров и сравнения моделей на обучающей выборке используется кросс-валидация. Итоговое качество оценивается на независимой тестовой выборке. |
| 5. Результат | В каком виде результат? | Для каждого объекта — рекомендованная цена в рублях и индикатор «цена завышена / занижена» относительно прогноза. |
| 5. Результат | Как поймём, что работает? | Сравнение прогноза с фактическими ценами сделок. |
