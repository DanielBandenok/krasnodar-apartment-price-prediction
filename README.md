# krasnodar-apartment-price-prediction




| __1.Бизнес задача__                                                         |                                                                                                                                                                                                                               |
| --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Что улучшаем?                                                               | Повышаем точность оценки рыночной стоимости квартир на вторичном рынке Краснодара. Цель — рекомендовать продавцам устанавливать обоснованную цену, а покупателям — оценивать адекватность стоимости предложения.              |
| Что сделают с прогнозом?                                                    | Пользователь вводит характеристики квартиры и получает рекомендованную цену в рублях и индикатор, является ли цена рыночной. Результат можно использовать при размещении объявления или принятии решения о покупке.           |
| __2. ML-задача__                                                            |                                                                                                                                                                                                                               |
| Для чего и когда прогноз?                                                   | Прогноз стоимости выполняется при оценке квартиры перед покупкой или размещением объявления, на основании известных признаков объекта.                                                                                        |
| Таргет: как посчитать из данных?                                            | Цена квартиры в рублях, указанная в объявлении о продаже. Для каждого объекта используется цена на момент сбора данных.                                                                                                       |
| Тип задачи                                                                  | Регрессия.                                                                                                                                                                                                                    |
| __3. Данные и признаки__                                                    |                                                                                                                                                                                                                               |
| Откуда данные, сколько их? Нет — где взять? (биллинг и CRM за 2 года)       | ~12 000 объявлений о продаже квартир на вторичном рынке Краснодара. Основной источник — API ЦИАН, вспомогательный — парсинг объявления Авито.                                                                                 |
| Признаки на момент прогноза (тариф, стаж, платежи, обращения до 1-го числа) | Общая/жилая площадь, площадь кухни, количество комнат, этаж, этажность дома, район, год постройки, тип дома, высота потолков, тип санузла, тип отопления.                                                                     |
| __4. Метрика и проверка__                                                   |                                                                                                                                                                                                                               |
| Метрика                                                                     | MAE                                                                                                                                                                                                                           |
| Бейзлайн без ML                                                             | Предсказываем стоимость квартиры на основе медианной цены квадратного метра для квартир с похожими характеристиками, умноженной на площадь объекта.                                                                           |
| Как делим данные? (по времени: обучаем на прошлых месяцах)                  | Данные разделяются на обучающую 80% и тестовую 20% выборки. Для подбора гиперпараметров и сравнения моделей на обучающей выборке используется кросс-валидация. Итоговое качество оценивается на независимой тестовой выборке. |
| __5. Результат__                                                            |                                                                                                                                                                                                                               |
| В каком виде результат?                                                     | Для каждого объекта — рекомендованная цена в рублях и идикатор «цена завышена / занижена» относительно прогноза.                                                                                                              |
| Как поймём, что работает?                                                   | Сравнение прогноза с фактическими ценами сделок.                                                                                                                                                                              |
